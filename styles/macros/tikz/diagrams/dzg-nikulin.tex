% =============================================================================
% The table of 2-elementary hyperbolic lattices (r, a, delta)
% =============================================================================
% Nikulin's table: the even hyperbolic 2-elementary lattices S of signature
% (1, r-1) that embed primitively in the K3 lattice II_{3,19}, by rank r,
% 2-rank a of the discriminant group A_S = (Z/2)^a, and parity delta
% (delta = 0 iff q_S takes values in Z/2Z). There are 75 triples (r, a, delta)
% at 64 points (r, a).
%
% Source: dzack_research.preamble.catalogue, _TwoElementaryTable (the 75-row
% table TwoElementary with a realizing orthogonal sum for every triple). The
% same 75 triples follow from Nikulin, "Integral symmetric bilinear forms and
% some of their applications" (1979), Thm. 3.6.2, applied to S of signature
% (1, r-1) and to its orthogonal complement in II_{3,19}, of signature
% (2, 20-r) with the same (a, delta). The two computations agree point for
% point. At (r, a) = (2, 2) both parities occur: U(2) has q values {0, 0, 0, 1}
% in Q/2Z, so delta = 0, and <2> + <-2> has q values {0, 1/2, 3/2, 0}, so
% delta = 1.
%
% The vertex mark encodes which delta occur at (r, a):
%   white   delta = 0 only
%   black   delta = 1 only
%   doubled both
%
%   \pic (N) {nikulin table};          grid, axes, and the 64 marked points
%   \pic[nikulin labels=none] {nikulin table};   without axis names and ticks
% The point (r, a) is the node <name>-<r>-<a>, e.g. (N-10-10) for the Enriques
% lattice U(2) + E_8(2). Figures loop over the data with
%   \foreach \r/\a/\m in \nikulinTwoElementaryPoints {...}

  1/1/black, 3/1/black, 9/1/black, 11/1/black, 17/1/black, 19/1/black,

  3/3/black, 5/3/black, 7/3/black, 9/3/black, 11/3/black, 13/3/black,
  15/3/black, 17/3/black, 19/3/black,

  16/4/black, 18/4/doubled,
  5/5/black, 7/5/black, 9/5/black, 11/5/black, 13/5/black, 15/5/black,
